# VM Pilot 🖥️

Веб-панель для мониторинга и управления виртуалкой на GitHub Actions
(Windows-раннер, который живёт максимум 6 часов).

## Возможности

- **Дашборд**: статус виртуалки в реальном времени (работает / остановлена,
  сколько работает, сколько осталось до 6-часового лимита), автообновление.
- **Ручное управление**: запуск, рестарт, остановка в один клик
  (через GitHub API, триггер `workflow_dispatch`).
- **История запусков**: таблица workflow runs со статусами и результатами.
- **Просмотр логов**: jobs запуска + tail лога прямо в браузере.
- **Аптайм**: суммарная статистика и график по дням за 14 дней.
- **Автопилот**:
  - *keep-alive* — поднимает виртуалку, если она упала (с паузой после ручной остановки);
  - *превентивный рестарт* — пересоздаёт запуск до 6-часового лимита GitHub без простоя.
- **Расписание**: cron-задачи на автозапуск (создание/вкл/выкл/удаление через UI).
- **Журнал событий**: все ручные и автоматические действия с метками времени.
- **Настройки**: токен, репозиторий, часовой пояс, параметры автопилота, пароль дашборда,
  кнопка «Проверить подключение».

## Быстрый старт (локально)

```bash
pip install -r requirements.txt
python app.py
# открыть http://localhost:5000
```

Тесты:

```bash
python -m unittest discover -s tests
```

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `GITHUB_TOKEN` | Personal Access Token (приоритетнее, чем токен в настройках) |
| `REPO_OWNER`, `REPO_NAME` | можно задать и через UI |
| `DASHBOARD_USER` / `DASHBOARD_PASSWORD` | логин в панель (без пароля — открыто всем) |
| `SECRET_KEY` | секрет сессий Flask |
| `PORT` | порт (PaaS обычно подставляет свой) |
| `VM_PILOT_DB` | путь к SQLite-базе |
| `VM_PILOT_NO_SCHEDULER=1` | не запускать фоновый планировщик (для тестов) |

Продакшен-запуск: `gunicorn --workers 1 --bind 0.0.0.0:$PORT app:app`
(воркер строго один, иначе фоновые задачи задвоятся).

## Токен GitHub

Нужен Personal Access Token с доступом к Actions:
- fine-grained: **Actions → Read and write** на нужный репозиторий;
- или классический: scopes **repo** + **workflow**.

Создание: GitHub → Settings → Developer settings → Personal access tokens.

## Деплой на Infrlo

1. Залей код в GitHub-репозиторий.
2. В дашборде Infrlo создай проект из этого репозитория (Python).
3. Команда запуска: `gunicorn --workers 1 --bind 0.0.0.0:$PORT app:app`.
4. Задай переменные: `GITHUB_TOKEN`, `DASHBOARD_USER`, `DASHBOARD_PASSWORD`,
   `SECRET_KEY` (любая длинная случайная строка).
5. Открой Настройки в панели и укажи owner / имя репозитория с workflow виртуалки.

> ⚠️ SQLite живёт в файле на диске. На тарифах с эфемерным диском история
> запусков и событий сбросится при редеплое — для долгой истории позже можно
> прикрутить внешнюю БД.
